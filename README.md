# VÉLORA — Where Style Meets You

A responsive luxury fashion storefront demo built with HTML5, CSS3, Vanilla JavaScript, Bootstrap 5 and Font Awesome.

## Run locally
Open `index.html` in a browser. For a more reliable local preview, use VS Code Live Server.

## Deploy to Netlify
1. Extract this ZIP.
2. Ensure `index.html` is in the root of the folder you upload.
3. Drag the `velora-store` folder contents (not the outer parent folder) into Netlify Drop, or push the folder to GitHub and import the repository into Netlify.
4. No build command or publish directory is required for this static project.

## Features
- Separate Men's and Women's catalogs.
- 24 demo products with PKR prices.
- Search, category filtering and sorting.
- Product details open in a new tab.
- LocalStorage cart and wishlist.
- Responsive navigation and product layouts.
- Demo checkout and contact/newsletter forms.

## Important notes
- Product photos are loaded from external Unsplash image URLs, so an internet connection is needed to view them. Fallback images are included for failed product images.
- Product names, prices, ratings, policies and descriptions are sample/demo content. Verify and replace them before selling real products.
- Cart and wishlist are stored locally in the browser. No server, real order submission, or payment gateway is included.
- External libraries and Google Fonts require internet access.
